# Hard filters

Reject a stop or day-shape if any of these apply. Record rejects in the region file under **never** or **rejected day shapes** with a one-line reason.

## Access and independence

- Requires a booked tour operator or hired guide to visit in practice
- No reliable independent access (tickets/permits only via package)
- Private property / no public visiting without arrangement
- Seasonal or permit-gated in a way that blocks casual self-guided visits

## Scooter / walk practicality

- Unsafe or impractical for the assigned mode (e.g. highway-only scooter slog with no payoff, or a “walk” day that needs a vehicle between every stop)
- No reasonable parking / drop-off for scooter trails
- Trail would exceed a reasonable day once travel time is included

## Worth-seeing bar

- Tourist-trap filler with weak consensus that it is “must see”
- Duplicate of a stronger stop already assigned to another trail (prefer the better day-shape; do not double-book)

## Puzzleability (Phase 2 relevance; soft filter in Phase 1)

- Nothing observable or interactive on-site (pure transit viewpoint with no readable detail) — flag as weak; prefer replacing in Phase 1 when alternatives exist

## Do not reject solely because

- Entry fee exists (paid entry can still be self-guided)
- Place is popular / busy
- Place appears on many tours (tours are a **signal**; convert if independently doable)
