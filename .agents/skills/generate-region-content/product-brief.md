# Product brief

Pleasure Island packages **must-see places** into **self-guided day-outs** so visitors skip heavy research.

## Intent

- Curate what is worth seeing in a region, not list everything
- One trail = one day or less (walk or scooter)
- Player flow: region → trail → ordered locations → steps at each location
- Save players from comparing dozens of blogs and Reddit threads

## What we are replicating

Tourist industry **day packages / classic itineraries**, converted to self-guided trails:

1. Start from package day-shapes
2. Keep only stops a visitor can do independently
3. Refine with Reddit, travel blogs, and reviews
4. Deduplicate so each must-see sits on at most one trail

## Transport

| Mode | Typical use |
| --- | --- |
| `walk` | Dense cores (old city, compact neighborhoods) |
| `scooter` | Spread-out viewpoints, temples, countryside day loops |

A region usually needs **both**.

## Out of product scope

- Multi-day treks packaged as one trail
- Experiences that require booking a tour operator / guide to access
- Places that are famous but not worthwhile for a first-time visitor’s limited time
- Treasure rewards (optional system; not part of this content pipeline)

## Domain terms (fixed)

- **region** — geographic grouping
- **chain** — location (map pin); UI says “location”
- **step** — ordered clue/puzzle inside a location
- **trail** — ordered playlist of locations (the day-out players browse and play)
