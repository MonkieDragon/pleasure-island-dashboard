# Quality rubric

Use this when drafting or revising portfolios and puzzles. Update from playtests via `lessons-learned.md`.

## Good trail (day-out)

- Clear theme or geography (not a random pin scatter)
- Fits in a day or less including travel for the assigned mode
- Ordered stops make sense on a map (minimal backtracking)
- Mix of payoff moments; not three near-identical temples in a row unless the trail’s point is a temple circuit
- Description sets expectations (walk vs scooter, vibe, roughly how long)

## Good location (stop)

- Independently visitable
- Worth a first-time visitor’s time
- Distinct role on the trail (anchor / contrast / finale)
- Enough on-site detail for at least one grounded step later

## Good step / puzzle (Phase 2)

- Grounded in what is actually at the place (prefer photos when available)
- Solvable on-site without external trivia apps
- Progressive hints when the step is a question type
- Difficulty matches trail tone (family-friendly vs sharper challenge)
- Prefer variety across a location: not five identical text answers
- Avoid fake plaque text or invented history; if unsure, use observation tasks or mark “verify on site”

## Step type guidance

| Type | Prefer when |
| --- | --- |
| `info` | Arrival context, etiquette, how to find the next spot |
| `text` / `number` | Readable detail on-site (sign, count, date, word) |
| `multiple_choice` | Observation with plausible distractors |
| `qr` | Real QR / code the player must find (only if it exists or you will place it) |
| `interactive` | Strong visual/physical beat; needs assets — draft carefully |

## Anti-patterns

- Isolated trail ideas that steal must-sees from a better day-shape
- Tour replication that keeps operator-only legs
- Puzzles that require knowing history the site does not show
- Overlong location chains (prefer fewer stronger steps)
